Couchcast

Movie night, no matter where everyone is.

One friend hosts and plays a movie from their computer. Everyone else joins with a code or link and watches in sync, with chat, reactions and subtitles. Video goes straight between your computers: no account, no upload, free.

Host a room

You pick the movie and control playback. Best on Chrome or Edge on a computer.

Join a room

Type the code your host sent, or just open their invite link.

Connection settings (if a friend can't connect)

Some networks block direct connections. A TURN relay fixes this. Everyone who has trouble should enter the same details here (or the host can put them in the file once).
